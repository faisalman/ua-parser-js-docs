# List of Detected Browser Engines

| Value | Description | Browser Examples |
|-|-|-|
| `Amaya` | A web editor and browser developed by the W3C. | Amaya |
| `ArkWeb` | An open-source engine for HarmonyOS Next mobile OS developed by Huawei. | Chrome (on HarmonyOS) |
| `Blink` | A highly popular open-source browser engine developed by Google as a fork of `WebKit` engine, used in browsers such as Chrome, Edge, Opera, Brave, and Vivaldi. | Chrome, Edge, Opera, Brave, Vivaldi |
| `Dillo` | A lightweight browser engine focused on minimalism and performance for low-resource systems. | Dillo |
| `EdgeHTML` | A proprietary browser engine developed by Microsoft for its older version of Edge browser. | Edge (legacy) |
| `Flow` | A proprietary browser engine developed by Ekioh, focusing on set-top boxes and embedded systems. | Flow |
| `Gecko` | An open-source browser engine by Mozilla, used in Firefox. | Firefox |
| `Goanna` | An open-source browser engine forked from `Gecko`, used in the Pale Moon browser. | PaleMoon |
| `iCab` | A browser engine used in the iCab web browser for macOS and iOS. | iCab |
| `KHTML` | An open-source browser engine used in the KDE project's Konqueror web browser. | Konqueror |
| `LibWeb` | An open-source browser engine for the SerenityOS operating system. | Ladybird |
| `Links` | A text-based browser engine used in the Links web browser. | Links |
| `Lynx` | One of the oldest text-based web browser engines. | Lynx |
| `NetFront` | An embedded browser engine commonly used in mobile and handheld devices. | NetFront |
| `NetSurf` | A lightweight browser engine designed for use on low-resource systems. | NetSurf |
| `Presto` | A proprietary browser engine developed by Opera Software, used in older versions of the Opera browser. | Opera Tablet |
| `Servo` | A high-performance browser engine originally developed by Mozilla, focused on security and parallelization. | Firefox (with Servo) |
| `Tasman` | A browser engine developed by Microsoft, used in the older versions of Internet Explorer for Mac. | IE (Mac) |
| `Trident` | A proprietary browser engine developed by Microsoft, used in Internet Explorer. | IE |
| `w3m` | A text-based open-source web browser engine. | w3m |
| `WebKit` | An open-source browser engine developed by Apple as a fork of `KHTML` engine, used in Safari and previously in Chrome. | Safari |

::: tip
Use the [`EngineName`](/api/submodules/enums/engine-name) enum from the `enums` submodule to reference browser engines in code.
:::
