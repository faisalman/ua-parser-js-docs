# 115 Browser

- **Developer:** 115 Technology
- **Development Status:** Active
- **Platforms:** Windows, macOS
- **Type:** Browser
- **Rendering Engine:** Blink

## User-Agent Examples

```sh
Mozilla/5.0 (Macintosh; Intel Mac OS X 10_16_0) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/83.0.4103.61 Safari/537.36 115Browser/24.3.0.3
```

## Code Example

```js
import { UAParser } from 'ua-parser-js';
import { BrowserName } from 'ua-parser-js/enums';

const parser = new UAParser();
const ua = 'Mozilla/5.0 (Macintosh; Intel Mac OS X 10_16_0) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/83.0.4103.61 Safari/537.36 115Browser/24.3.0.3';

const browser = parser.setUA(ua).getBrowser();

console.log(browser);
// {name: "115", version: "24.3.0.3", major: "24"}

console.log(browser.is(BrowserName.115));
// true
```
