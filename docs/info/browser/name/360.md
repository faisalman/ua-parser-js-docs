# 360 Browser

- **Developer:** Qihoo 360
- **Development Status:** Active
- **Released:** 2008
- **Platforms:** Windows, macOS, Android, iOS
- **Type:** Browser
- **Rendering Engine:** Trident (compatibility mode), Blink (desktop and Android), WebKit (iOS)

## Overview

360 Browser is a web browser developed by Qihoo 360.

## Code Example

```js
import { UAParser } from 'ua-parser-js';
import { BrowserName } from 'ua-parser-js/enums';

const parser = new UAParser();
const ua = 'Mozilla/5.0 (iPhone; CPU iPhone OS 12_4_1 like Mac OS X) AppleWebKit/607.3.9 (KHTML, like Gecko) Mobile/16G102 QHBrowser/317 QihooBrowser/4.0.10';

const browser = parser.setUA(ua).getBrowser();

console.log(browser);
// {name: "360", version: "4.0.10", major: "4"}

console.log(browser.is(BrowserName.360));
// true
```
