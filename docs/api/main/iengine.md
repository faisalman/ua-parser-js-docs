# `IEngine`

```js
{
    name: "",
    version: ""
}
```

## Properties

### `name?: string`

The name of the rendering engine.

::: tip
See the [list of browser engines](/info/engine/name).
:::

### `version?: string`

The detected engine version, determined dynamically from the user-agent string.
