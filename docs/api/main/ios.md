# `IOS`

```js
{
    name: "",
    version: ""
}
```

## Properties

### `name?: string`

The name of the detected operating system.

::: tip
See the [list of operating systems](/info/os/name).
:::

### `version?: string`

The detected operating-system version, determined dynamically from the user-agent string.
